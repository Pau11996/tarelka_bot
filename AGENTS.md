# Правила работы с проектом

## Git push и деплой

- Перед обновлением сервера или публикацией нового APK проверить, что коммит релиза уже отправлен в удалённый репозиторий GitHub.
- Если коммит ещё не отправлен, приостановить деплой и попросить пользователя сделать `git push` либо явно разрешить агенту выполнить push. После push проверить наличие нужного коммита в удалённой ветке.
- Обновлять код на сервере из удалённого репозитория через Git. Не переносить неопубликованные локальные коммиты или исходники напрямую на сервер через SSH/SFTP, `git bundle`, архивы или другие способы обхода push.
- Если push недоступен или отклонён проверкой разрешений, сообщить об этом пользователю и дождаться решения; не заменять push прямым переносом локального кода.
- Готовый APK можно загружать на сервер как артефакт релиза после проверки, что он собран из опубликованного коммита.
