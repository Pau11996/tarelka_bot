# Неглубокие приседания

Одобрено пользователем и включено в приложение 5 ноября 2026 года.
Анимация используется в плеере тренировок и карточках через `ExerciseFigure`.

Первое упражнение, приведённое к выбранному пользователем образцу «Присед + удар».
Обычный `squat` теперь использует детальный векторный персонаж через
`FullBodyCharacter` / `RecordedWorkoutCharacter`, включая подсказки фаз, паузу,
остановку в фоне и режим уменьшения движения.

Рисунок происходит из существующего `squatKickContours.json`. Происхождение
этого материала описано в `squat-kick-reference.md`; это производная от ранее
предоставленной записи, а не новая независимая иллюстрация. Исходный образец
`squat_kick` не меняется.

`mobile/scripts/build-shallow-squat.cjs` использует пять поз исходного опускания
(отсчёты 36, 38, 40, 42, 44), в которых ноги уже возвращены на пол. Глубина
ограничена промежуточной позой; удары и глубокое нижнее положение исключены.
Контуры пересэмплированы и согласованы по обходу, промежуточные положения
сохранены в `shallowSquatContours.json`. Нижняя часть силуэта, обувь и подошва
неподвижны; переход к голени сглажен выше щиколотки.

Цикл — 120 отсчётов при 30 кадрах/с, 4 секунды: стойка, плавное опускание,
короткая пауза, подъём, стойка. Нулевые скорости на концах движения обеспечены
quintic easing. Рендер использует локальные SVG-контуры; расчёт промежуточных
контуров выполняется только при подготовке ассета. Маска пересоздаётся вместе
с позой через существующий компонент, учитывающий кеш `react-native-svg` на Android.

Для воспроизведения подготовки:

```sh
node mobile/scripts/build-shallow-squat.cjs
node mobile/scripts/render-shallow-squat.cjs
node mobile/scripts/check-shallow-squat.cjs
cd mobile
npm run typecheck
node --test tests/shallowSquatMotion.test.cjs tests/fullBodyMotion.test.cjs tests/squatKickMotion.test.cjs tests/recordedWorkoutClipLifecycle.test.cjs tests/workoutMotionLifecycle.test.cjs
```

Проверено: TypeScript и 19 тестов движения/жизненного цикла проходят.
Покадровая проверка всех 120 SVG подтверждает цельный силуэт, неподвижные
стопы и совпадение кадров на стыке цикла. Максимальное изменение площади
силуэта между соседними кадрами — 0,55%. На физическом устройстве эта замена
пока не проверялась; новый APK не собирался и не публиковался.

Артефакты предпросмотра и проверки находятся в
`outputs/2026-11-05-squat-animation/`. Замена касается только анимации `squat`;
программа курса, повторы, интервалы и серверные данные сохранены.
