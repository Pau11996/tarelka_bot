# ТАРЕЛКА 1.0.10

Android versionCode: 11. Профиль EAS preview, API `https://tarelkaa.by/api`.

## Изменения

- В каталоге два курса на четыре недели: домашний «Всё тело» и «Всё тело + прогулки».
  Домашний курс содержит 24 занятия с короткой разминкой, двумя кругами и завершением.
- Программа и обложки выбираются по полу в профиле. Если пол не указан, используется
  женский вариант. Мужская программа содержит больше отжиманий и три варианта
  упражнения по уровню нагрузки: от стены, с колен и от пола.
- Для каждого курса используются отдельные фотографии дома и на прогулке.
  Изображения включены в приложение и доступны офлайн.
- Прогресс хранится отдельно для каждого курса. Смена пола сохраняет прогресс,
  начатую тренировку и возможность синхронизировать прежние офлайн-занятия.
- Добавлены анимации отжиманий и отображение кругов; сохранены локальные улучшения
  движений. Каталог v5 совместим с прежними определениями тренировок.
- В общую ветку mobile включён редизайн сайта с акцентом на приложение.
  Сохранены актуальные месячные тарифы, оферта и реквизиты.

## Проверка и публикация

После слияния прошли 356 мобильных тестов, 40 проверок backend, 10 тестов
рендера сайта, 14 JavaScript-тестов сайта и TypeScript. Вёрстка проверена
локально в Chrome при ширине 1440 и 390 пикселей. Это проверки исходников;
установка и работа готового APK проверяются отдельно после сборки.

Перед публикацией проверить APK: версия 1.0.10, versionCode 11, пакет
`by.tarelka.app`, прежняя подпись и публичный HTTPS-адрес API. Новых миграций нет:
текущая ревизия БД — `027_google_login`.

Сначала отправить релизный коммит в GitHub с разрешения пользователя и проверить
его наличие в удалённой ветке. APK собирать из чистой копии опубликованного коммита.
Сервер обновлять через Git, сохранив БД, конфигурацию, предыдущие образы и APK
для отката. Сначала обновить мобильный API и проверить каталоги v4/v5 и прогресс
обоих курсов, затем опубликовать APK. Проверить скачиваемый файл и доступность API.
Результаты записать в `outputs/releases/release-1.0.10-status.json`.
