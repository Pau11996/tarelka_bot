# ТАРЕЛКА 1.0.2

Android versionCode: 3. Профиль сборки: EAS preview, API https://tarelkaa.by/api.

## Изменения

- Независимая очередь сообщений: можно продолжать писать и добавлять фото во время загрузки и анализа. Исходящие сообщения и вложения восстанавливаются после перезапуска в пределах аккаунта.
- Избранное: общий порядок записей в приложении и Telegram, самостоятельная карточка и исправление шаблона без изменения прошлых записей дневника.
- Профиль: видимый результат сохранения и выбор действия при уходе с несохранёнными изменениями; поздний ответ обновления не отменяет сохранение.
- Дневник: хроника ближе к калориям и БЖУ, дополнительные показатели в сворачиваемом блоке. Уточнены источники активности и значение сахара.
- Голос: остановка записи, проверка текста и отправка подписаны отдельно. Подписка показывает фактические лимиты аккаунта.
- Улучшены представление наград и доступ к защищённым фотографиям.

## Проверки перед сборкой

- 606 серверных тестов.
- 183 мобильных теста и TypeScript.
- Лендинг: 8 Python-тестов, 10 JavaScript-тестов, проверка shell-синтаксиса.
- Визуальная проверка компонентов дневника на демонстрационных данных.
- Проверки на реальном телефоне (восстановление после закрытия, фон, системная навигация) остаются ручными.

## Публикация

1. Собрать APK из зафиксированного коммита, проверить версию, подпись и адрес API.
2. Получить явное разрешение на git push, если коммита ещё нет на GitHub; проверить SHA удалённой ветки.
3. Сохранить резервную копию БД и старый APK. Получить опубликованный коммит на сервере через Git.
4. Обновить API и бота с миграцией `023_favorite_order` до публикации APK. Миграцию выполнить один раз до запуска новых процессов.
5. Загрузить проверенный APK как артефакт, обновить контейнер лендинга, проверить health API и SHA-256 публичной загрузки.

Демонстрационная оплата остаётся включённой. Настоящие платежи этим релизом не запускаются.
