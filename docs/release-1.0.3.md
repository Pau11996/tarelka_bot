# ТАРЕЛКА 1.0.3

Android versionCode: 4. Профиль сборки: EAS preview, API https://tarelkaa.by/api.

## Изменения

- Исправлен запуск микрофона после выдачи разрешения и возврата в приложение.
- Ошибки анализа отображаются спокойнее; их можно закрыть крестиком.
- Экспорт дневной нормы: карточка Д6 с котом, реальные КБЖУ, предпросмотр и отправка PNG из приложения.
- Telegram: «Сегодня» → «Поделиться нормой», карточка для пересылки и оригинальный PNG. Экспорт не удаляется автоматически и не расходует лимиты анализа.

## Проверки

- 212 мобильных тестов и TypeScript; сборки JavaScript для Android и web.
- 74 серверных теста, включая полный сценарий Telegram через локальный транспорт.
- Проверены PNG 1080 × 216, стартовая норма, крупные значения, повторные нажатия и ошибки.
- Проверено включение шаблона и шрифтов в серверный пакет.
- Проверка на физическом телефоне остаётся ручной.

## Публикация

Перед обновлением сервера и публикацией APK проверить наличие коммита релиза на GitHub.
Код сервера обновлять через Git. Сверить подпись APK с предыдущим релизом,
версию, номер сборки и SHA-256 публичной загрузки. Проверить API и запуск бота.
После успешной проверки новой версии удалить старые APK с сервера и компьютера.

Новых миграций БД нет; текущая версия схемы — `023_favorite_order`.
