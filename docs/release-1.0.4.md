# ТАРЕЛКА 1.0.4

Android versionCode: 5. Профиль EAS preview, API `https://tarelkaa.by/api`.

## Изменения

- Пятая вкладка «Тренировки», доступная бесплатно всем пользователям приложения.
- Шесть домашних комплексов, собственный SVG-персонаж и демонстрации движений.
- Таймер, повторы с подтверждением, отдых, пауза, пропуск и досрочное завершение.
- Каталог без сети после первой загрузки, восстановление занятия и очередь результатов.
- История и настройки аккаунта, ручное или автоматическое добавление активности в дневник.
- Серверная оценка активных калорий по MET и весу, без учёта пауз и отдыха.

В Telegram видны добавленные записи активности; прохождение остаётся в приложении.
Сохранение не использует ИИ и не расходует лимиты. Демооплата остаётся включённой.

## Проверки

- TypeScript, мобильные и серверные тесты, отдельный тест миграции и её отката.
- Android-бандл и нативная отладочная сборка.
- Полное занятие в браузере, пауза и перезапуск, повторы, дополнительный отдых,
  офлайн-результат с последующей синхронизацией, дневник, другой аккаунт.
- Пять вкладок на экранах шириной 360 и 390 пикселей.
- Физический Android: проверка блокировки экрана, звука и полного прохода остаётся ручной.

## Выпуск

Сначала проверить релизный коммит в GitHub. На сервере получить его через Git,
сделать резервную копию БД, применить `024_workouts`, обновить API и проверить
каталог. Затем опубликовать самостоятельный APK, собранный EAS из того же коммита.
Проверить versionCode, совпадение подписи с 1.0.3 и SHA-256 публичной загрузки.
Сохранить предыдущий APK для отката.

Подробнее: [устройство модуля и API](workouts.md).
