# ТАРЕЛКА 1.0.5

Android versionCode: 6. Профиль EAS preview, API `https://tarelkaa.by/api`.

## Изменения

- Firebase/FCM v1 для Android push, ключ отправки подключён в EAS.
- Подтверждение почты шестизначным кодом при создании аккаунта.
- Доработанные иллюстрации тренировок, отдельные записанные движения всех
  двенадцати упражнений занятия «Всё тело · День 1», очищенные контуры и опоры.
- Каталог тренировок версии 2; старые приложения продолжают получать версию 1.
- Удаление сообщений с ошибками анализа, исправления отображения лимитов.
- Проверка роста и рассчитанной нормы питания, обновлённая политика
  конфиденциальности и шаблон карточки дневной нормы.

Демооплата сохраняется. Проверка push на физическом Android остаётся ручной.

## Проверки перед сборкой

Прошли 283 мобильных теста, 688 серверных проверок и проверок страниц сайта,
TypeScript и тесты JavaScript лендинга. FCM validate-only возвращает HTTP 200,
Expo prebuild и Gradle `processReleaseGoogleServices` проходят.

## Выпуск

Проверить TypeScript, мобильные и серверные тесты. Отправить релизный коммит в
GitHub и проверить его наличие в удалённой ветке. Собирать APK из отдельной чистой
копии этого коммита; приватный Firebase-ключ в исходники не включать.

На сервере сохранить резервную копию БД, предыдущего APK, конфигурации и образов.
Получить релизный коммит через Git, настроить SMTP для API, применить
`025_email_verification` и обновить API/бота. Проверить авторизацию, оба каталога
тренировок и конфигурацию доставки почты. Затем опубликовать APK и обновлённый
лендинг. Проверить подпись приложения, versionCode, встроенный Firebase-проект
и SHA-256 полной публичной загрузки.

Существующие аккаунты сохраняются. Новая регистрация старого APK требует
обновления клиента: API теперь возвращает заявку на подтверждение вместо сессии.
