# ТАРЕЛКА 1.0.6

Android versionCode: 7. Профиль EAS preview, API `https://tarelkaa.by/api`.
Выпуск для скачивания APK с лендинга; публикация в магазинах отложена.

## Изменения

- Курс домашних тренировок на 28 дней с выбором нагрузки, сохранением прогресса
  на сервере и синхронизацией результатов после восстановления связи.
- Новые движения для упражнений на полу, доработки иллюстраций и жизненного
  цикла анимаций при переключении упражнений.
- Обновлённая иллюстрация на экране входа.
- Ранее подготовленный экран недоступности покупки вместо демонстрационной
  оплаты. Реальные покупки не подключены; действующие подписки и лимиты
  продолжают определяться сервером. Новый план переработки подписок не внедрён.

## Совместимость

Новый курс использует каталог тренировок версии 3 и миграцию
`026_workout_course`. Сервер обновляется до публикации APK. Каталоги версий 1 и 2
сохраняются для предыдущих приложений и отложенной отправки результатов.
Пакет `by.tarelka.app` и сертификат подписи должны совпадать с версией 1.0.5.

## Проверки и публикация

Локально пройдены TypeScript, 302 мобильных теста, полный набор из 692 серверных
и HTML-тестов. После добавления проверки миграции отдельно пройдены все 19
тестов тренировок. SQL миграции также сгенерирован для PostgreSQL.

Проверить TypeScript, мобильные и серверные тесты, применение миграции с
сохранением существующих настроек. Проверить самостоятельный запуск APK,
встроенный публичный API, версию, сертификат, Firebase и ресурсы тренировок.
Отдельно проверить вход, добавление еды, тренировку и синхронизацию курса.

Релизный коммит сначала отправить в GitHub и проверить наличие в удалённой
ветке согласно `AGENTS.md`. Собирать APK из отдельной чистой копии этого коммита.
Сервер получает код через Git; перед обновлением сохраняются БД, конфигурация,
образы работающих сервисов и APK 1.0.5. Секреты остаются вне исходников.

После проверки API заменить `/downloads/tarelka.apk`, пересобрать лендинг и
сверить SHA-256 полной публичной загрузки. Только затем удалить конкретные APK
версий старше 1.0.5 локально и на сервере. Сохранить новый APK 1.0.6, предыдущий
1.0.5 и резервные копии БД. Результаты проверок и публикации записать в
`outputs/releases/release-1.0.6-status.json`.
