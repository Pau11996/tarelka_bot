# ТАРЕЛКА 1.0.8

Android versionCode: 9. Профиль EAS preview, API `https://tarelkaa.by/api`.

## Изменения

- Раздел тренировок открывается каталогом курсов. Карточка «Всё тело» содержит
  новую сгенерированную обложку, срок курса, длительность занятий и число упражнений.
  Нажатие открывает отдельную страницу с кнопкой «Начать курс», выбором нагрузки
  и программой по дням. Начатое занятие можно продолжить после паузы.
- Голосовое сообщение сразу появляется в чате. Распознавание и анализ выполняются
  одной серверной задачей. Нераспознанная запись получает карточку с нулевыми
  калориями; попытка возвращается в лимит. Старый формат голосовых поддерживается.

## Проверка и публикация

Проверить TypeScript, мобильные, серверные и HTML-тесты. Проверены каталог,
страница курса на ширине 320 и 390 пикселей, запуск первого занятия и возвращение
к нему после паузы. Для релиза нужны проверка версии, подписи APK и публичной
загрузки. Новых миграций нет: текущая ревизия БД — `027_google_login`.

Сначала отправить релизный коммит в GitHub и проверить удалённую ветку.
APK собирать из чистой копии опубликованного коммита. Сервер обновить через Git,
сохранив БД, конфигурацию, предыдущие образы и APK для отката. Сначала обновить
мобильный API, затем опубликовать APK. Результаты записать в
`outputs/releases/release-1.0.8-status.json`.
