# ТАРЕЛКА 1.0.9

Android versionCode: 10. Профиль EAS preview, API `https://tarelkaa.by/api`.

## Изменения

- Курс «Всё тело» переработан: 5–6 основных упражнений за тренировку,
  разминка и заминка, чередование силовых дней, прогулок и восстановления.
  Убраны сложные движения и автоматическое увеличение нагрузки по календарю.
  Полная программа по дням описана в `docs/workouts.md`.
- После силового занятия можно оценить нагрузку. Две лёгкие тренировки подряд
  дают предложение повысить её; тяжёлая — снизить. Изменение требует нажатия
  пользователем и действует на следующие занятия.
- Программа курса сворачивается. Выбор нагрузки содержит только названия уровней.
  Перед началом есть 15 секунд на подготовку; после упражнений — отдых
  15–30 секунд, включая последнее. Ожидание можно продлить на 20 секунд,
  приостановить или пропустить.
- Каталог версии 4 сохраняет прежние версии тренировок для истории,
  незавершённых занятий и синхронизации. Прогресс курса сохраняется.

## Проверка и публикация

Проверить TypeScript, мобильные, серверные и HTML-тесты. Проверить APK:
версия 1.0.9, versionCode 10, прежняя подпись, публичный HTTPS-адрес API.
Новых миграций нет: текущая ревизия БД — `027_google_login`.

Сначала отправить релизный коммит в GitHub и проверить удалённую ветку.
APK собирать из чистой копии опубликованного коммита. Сервер обновить через Git,
сохранив БД, конфигурацию, предыдущие образы и APK для отката. Сначала обновить
мобильный API, проверить выдачу каталогов 3 и 4, затем опубликовать APK.
Результаты записать в `outputs/releases/release-1.0.9-status.json`.
