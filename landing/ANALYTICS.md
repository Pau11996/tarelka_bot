# Аналитика «Тарелки»

Поток: `G-DBX8MSSJDK`. Домен: `https://tarelkaa.by`. Обновлено 13 октября 2026.

## Что измеряется на сайте

| Событие | Триггер | Дополнительные параметры |
|---|---|---|
| `page_view` | Google tag запускается после согласия, один config на загрузку страницы | URL, заголовок, источник перехода |
| `telegram_click` | Клик по ссылке именно на публичного бота, включая среднюю кнопку мыши | `cta_placement`, `cta_source`, `page_type`, `page_path`, `link_url` |
| `calculator_used` | Успешный расчёт порции; ошибки ввода не учитываются | `calculator_name`, `page_type`, `page_path` |
| `diary_template_download` | Клик по скачиванию CSV-шаблона | `file_name`, `file_extension`, `page_type`, `page_path` |

`telegram_click` означает намерение открыть бота. Он не подтверждает `/start`, первый анализ еды или оплату. `diary_template_download` фиксирует клик, а не подтверждённое сохранение файла на диск. Существующие параметры Telegram `start` сохраняются; связи с личностью посетителя GA4 не добавлено.

В параметры событий не включаются значения калькулятора, результаты вычислений, данные профиля, Telegram ID, сообщения, фото и содержимое дневника. Произвольные query-параметры и fragment удаляются из явно передаваемого page_location, сохраняются только UTM. В UTM нельзя помещать персональные данные. Внешний referrer сокращается до origin.

## Consent и локальная разработка

Basic consent: Google tag не загружается до согласия, события до согласия не копятся и не отправляются задним числом. Отказ не ограничивает функции сайта. Выбор хранится в localStorage до 180 дней; при отзыве сбор отключается, cookie `_ga` и `_ga_DBX8MSSJDK` удаляются и вкладка перезагружается. Изменение выбора синхронизируется между вкладками.

Скрипт работает только на hostname из `LANDING_ORIGIN`. Исключение — явный `?analytics_debug=1` на loopback-адресе; в этом режиме события отправляются в тот же поток с `debug_mode: true`. Для тестов без отправки в Google используются Node VM и поддельная очередь Google tag.

Нельзя включать дублирующий Google tag через GTM или создавать ещё одно событие `telegram_click` на основе автоматического `click`: сайт уже отправляет его. Автоматический `click`, если включён в расширенной статистике, является отдельным общим событием.

## Что завершить в кабинете GA4

ID потока разрешает отправку событий, но не даёт доступ к настройкам или отчётам. Для пунктов ниже нужна авторизованная сессия владельца/редактора.

1. Проверить правильность домена веб-потока и наличие Google tag в Realtime / DebugView после согласия.
2. Отметить `telegram_click` как ключевое событие. Для оценки доли визитов с переходом выбрать подсчёт один раз за сеанс. События калькулятора и шаблона пока оставить вспомогательными.
3. Создать пользовательские параметры с областью «Событие»: `cta_placement`, `cta_source`, `page_type`, `calculator_name`. Параметры отправляются уже сейчас; регистрация нужна для использования в стандартных отчётах и исследованиях.
4. Проверить расширенную статистику. Просмотры, прокрутку и исходящие клики можно оставить; взаимодействия с формами отключить, если они не нужны — отправка калькулятора не является заявкой.
5. Связать ресурс Search Console для `tarelkaa.by` с этим веб-потоком после подтверждения домена. Регистрация GA4 не подтверждает владение в Search Console и не отправляет sitemap.
6. В Search Console отправить `https://tarelkaa.by/sitemap.xml` и проверить главную и статьи через «Проверка URL».

Не заявлять, что пункты кабинета выполнены, пока это не подтверждено его интерфейсом. Локальные тесты проверяют триггеры и формирование команд Google tag, но не доказывают появление событий в отчётах Google.

## Источники

Проверка реализации: 6 тестов статической сборки, 7 тестов событий/согласия и 3 теста расчёта порции прошли. Через локальный nginx проверены 8 публичных страниц, ассеты и исключение админки. В браузере проверены отказ, сохранение выбора, разрешение загрузки Google tag, отзыв согласия, успешный и ошибочный расчёт. Поступление событий в отчёты Google пока не подтверждено: кабинет запрашивает вход. На момент проверки публичная главная `https://tarelkaa.by/` ещё не содержала скриптов; обновлён только локальный контейнер на 8080.
